# Literature notes

Raw findings from a literature search on 2026-11-23, one file per topic. They
were compiled by research agents and are **not yet verified against the primary
sources**; several databases blocked automated access, so some values come from
abstracts or review articles (flagged in each file). Check a value at its
source before turning it into a coaching threshold.

| File | Topic |
| --- | --- |
| [forehand.md](forehand.md) | Forehand groundstroke |
| [backhand.md](backhand.md) | One- and two-handed backhand, slice |
| [serve-volley.md](serve-volley.md) | Serve, smash, volley; stroke classification |
| [racket-dynamics.md](racket-dynamics.md) | Timing profiles, wrist and grip, racket IMUs, feedback and motor learning; evidence for the app's heuristics |

Thresholds actually used by the app, with their sources, are in
[../metrics.md](../metrics.md).
